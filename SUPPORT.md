# Support

AI Usage Monitor is currently a release-candidate open-source project.

## Questions and reproducible problems

Use GitHub Issues:

https://github.com/lingfeijiao-oss/ai-usage-monitor/issues

Choose the issue form that best matches the problem:

- Bug report
- Installation or startup problem
- Feature request

## Before filing an issue

Please include:

- operating system and architecture;
- AI Usage Monitor version;
- Codex version when relevant;
- minimal reproduction steps;
- sanitized screenshots or logs when useful.

Do not include:

- API keys or OAuth tokens;
- browser cookies;
- account identifiers that are not necessary;
- prompt or response bodies;
- private Codex rollout content;
- proprietary source-code bodies.

## Release-candidate trust warnings

Windows and macOS artifacts are currently unsigned. macOS DMGs are also not
Apple-notarized yet. Operating-system reputation or trust warnings are expected
for the current release candidate.

## Security reports

Read `SECURITY.md` before reporting a security issue. Do not place secrets or
sensitive reproduction data in a public GitHub Issue.
